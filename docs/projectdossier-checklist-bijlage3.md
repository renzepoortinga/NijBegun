# Projectdossier-checklist — BRL 9500-W Bijlage 3 (+ ISSO 82.1 §5.7)

Afvinklijst die de adviseur **per opname** doorloopt voor de **energielabel-route (A)**. Bron: BRL 9500-W
(aangewezen 29-05-2026), Bijlage 3 + §4.2.7; ISSO 82.1 7e druk §5.7. Bewaarplicht **min. 15 jaar** (§6.7.4),
AVG-conform. Dit is een **bewustwordings-/borgingsdocument** naast de KWACO-validator (die nu alleen de
Nij Begun-route dekt). "Tool" = de tool levert dit (deels) automatisch; "Adviseur" = handmatig aanvullen.

> Doel (§4.2.7): de invoer **reproduceerbaar en toetsbaar** maken — herleidbaar naar gebouw/kavel/bouwnummer,
> met **herkomst per gegeven** en **controlebewijs**.

## A. Algemene projectgegevens
- [ ] Postcode + huisnummer · adres — *Tool (dossier/out/projects)*
- [ ] BAG pand-ID + verblijfsobject-ID — *Adviseur (roadmap: tool)*
- [ ] Opdrachtgever (naam/rol/contact); registratie alleen in opdracht — *Adviseur*
- [ ] Doel: toets Bbl / oplevering / bestaand — *Adviseur*
- [ ] Enkelvoudig of seriematig · nieuwbouw/renovatie/bestaand — *Adviseur*
- [ ] Opname-soort: **basis (EP-W/B)** of **detail (EP-W/D)** — *Adviseur*
- [ ] Opnamedatum + registratiedatum — *Adviseur*

## B. Tekeningen & maatvoering
- [ ] Plattegrond (bouwtekening of schets) met maatvoering + indeling — *Tool (MagicPlan) + Adviseur*
- [ ] Doorsnede (tekening/schets/foto) met hoogte (mag uitdraai opname-instrument) — *Tool (MagicPlan) + Adviseur*
- [ ] Aantekeningen (bv. locatie installaties op plattegrond) — *Adviseur*

## C. Bouwkundige gegevens
- [ ] Ingevoerde oppervlaktes vloer/dak/gevels/ramen/panelen (mag uitdraai opname-instrument) — *Tool ✅*
- [ ] Bouwjaar en/of renovatiejaar + **toelichting op de ingreep** — *Tool (jaar) + Adviseur (toelichting)*
- [ ] Type dak (+ bouwtekening of foto) — *Tool ✅ + foto Adviseur*
- [ ] Beschrijving wijze bepaling thermische eigenschappen (isolatiemateriaal + dikte **óf**
      bouwjaarklasse-onderbouwing) — *Adviseur (tool levert forfait op bouwjaar)*
- [ ] Onderbouwing schematisering / bepaling rekenzones — *Adviseur*
- [ ] Onderbouwing 'inklappen'/forfaitair (terugvallen op forfaitaire waarden, ISSO 82.1) — *Adviseur*

## D. Installatietechnische gegevens (per stuk: type + foto/factuur)
- [ ] Locatie + type warmte-/koudeopwekker ruimteverwarming/-koeling — *Tool (deels) + foto Adviseur*
- [ ] Type ventilatiesysteem — *Tool (A–E) + foto Adviseur*
- [ ] Type warmtapwaterinstallatie — *Tool (deels) + foto Adviseur*
- [ ] Type gebouwgebonden energieproductie (PV/zonthermisch) — *Tool (PV ✅) + foto Adviseur*

## E. Onderbouwing & bewijslast
- [ ] **Herkomst per gegeven** (opdrachtgever/aannemer/eigen waarneming) + aannemelijkheid juistheid — *Adviseur*
- [ ] **Controlebewijs** bij door derden aangeleverde gegevens — *Adviseur*
- [ ] Gecontroleerde kwaliteits-/gelijkwaardigheidsverklaringen (BCRG) — merk + type + bewijs (foto/factuur) — *Adviseur*
- [ ] Productdocumentatie fabrikant (+ DoP bij detailopname/samengestelde constructies) — *Adviseur*
- [ ] Facturen op naam/adres (waar van toepassing) — *Adviseur*
- [ ] Onderbouwing gebruikte forfaitaire waarden (toets Bbl) — *Adviseur*
- [ ] Bewijs informeren opdrachtgever (§4.3.1) — *Adviseur*
- [ ] Bewijsmateriaal met **inhoudsopgave** + overzicht beschikbaar gestelde gegevens + wie aanleverde — *Adviseur*

## F. Foto's
- [ ] Overzichts- **én** detailfoto's met leesbare relevante info (typeaanduiding/maatvoering),
      **zichtbare samenhang**, door adviseur zelf, **datum ≤ opnamedatum** — *Adviseur (tool: foto-checklist)*
- [ ] Identificatie-overzichtsfoto's woning (optioneel GPS/datum/tijd) — *Adviseur*
- [ ] **Bij oplevering / detailopname** — thermische schil-bewijs:
  - [ ] isolatiedikte met **duimstok** (aanliggend/loodrecht), per dikte/type — *Adviseur*
  - [ ] type isolatiemateriaal (foto merk/type + attest) — *Adviseur*
  - [ ] plaatsing/aansluiting isolatie — min. **4 plekken**; prefab + niet-prefab beide — *Adviseur*

## G. Berekening, rapport & registratie
- [ ] Opnameformulier/invoerfile incl. opnamedatum + naam + registratienummer adviseur — *Tool (deels) + Adviseur*
- [ ] **EPA-computerdatabestand** + **software-versie** (geldig op registratiedatum) — *Adviseur (roadmap: tool)*
- [ ] Volledige rapportage/uitvoerfile van het rekenprogramma (Vabi) — *Adviseur*
- [ ] Elektronische bestanden berekeningen (+ GTO/koellast indien gemaakt) — *Adviseur*
- [ ] WLC-GWP-berekeningen (nieuwbouw > 1000 m², vanaf 2028) — *Adviseur*
- [ ] **Registratiegegevens EP-Online**: registratiedatum, naam + registratienr **opnemende én registrerende**
      adviseur, registratienummer rapport — *Adviseur*

## H. Bijzondere situaties
- [ ] **Representativiteit** (seriematig): onderbouwing toelaatbaarheid + deelverzameling + steekproef +
      kenmerken + types + wijze vaststellen — *Adviseur (buiten toolscope, ISSO H17)*
- [ ] **Herlabelen** (≤ 24 mnd): overzicht latere wijzigingen (Bijlage 6a) + bewijslast + uitvoerfile +
      EP-Online + offerte/opdracht/factuur + PV-beschaduwingsfoto's; **als addendum** — *Adviseur*
- [ ] Tijdens bouw/renovatie verzamelde, bij oplevering niet-waarneembare gegevens (Bijlage 5) — *Adviseur*
- [ ] Correspondentie bij klachten — *Adviseur*

**Kritieke afwijkingen (CI-controle, vermijden):** 'onbekend' bij waarneembaar gegeven · woning niet bezocht
terwijl het moest · niet-gevalideerde informatiebron · onjuiste/onvolledige bewijslast · onjuiste EP-Online-
registratie (verkeerd opname-type) · adviseur niet in kwaliteitssysteem/EP-Online/CRT · ≥ 5 opname-afwijkingen
· EP2-afwijking ≥ 1% (grenswaarden 10 kWh/m² / 8% / 35 kWh/m²).
