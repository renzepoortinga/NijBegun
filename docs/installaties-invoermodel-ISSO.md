# Installaties — invoer-model (ISSO 82.1 + NTA8800-opnameformulier → VABI EPA 12)

Bron: multi-agent ISSO/opnameformulier-workflow (22-6-2026), getoetst aan ISSO 82.1 7e druk +
het officiële NTA8800 W-opnameformulier. Dit is de **spec** voor het wiren van de installaties in de
tool (dossier → VABI Installatiebibliotheek + MagicPlan-form + parser). Codes die LIVE in EPA zijn
bevestigd staan in `vabi/refs/installatie_enums_EPA.md`; 'TE HARVESTEN' = nog 1 EPA-export nodig
(golden rule: niet gokken). PV + verwarming-gasketel/tapwater-anker zijn al gewired+geverifieerd.

> **STATUS (23-6-2026): de MagicPlan-form "Installaties" implementeert de KERN van dit model** —
> conditioneel: ventilatie + verwarming (opwekker→HR-klasse/WP/afgifte/aanvoertemp/jaar) + koeling +
> tapwater + **uitgebreide zonne-energie** (PV paneeltype mono/poly + fabricagejaar + bouwintegratie +
> oriëntatie + hellingshoek + aantal + Wp; zonneboiler; accu) + **7 foto-velden** (vooraanzicht/huisnummer
> verplicht). De parser (`magicplan/statistics_csv.py`) leest al deze velden. De velden met 'TE HARVESTEN'
> hieronder zijn bewust nog niet in de form gezet (worden in Vabi aangevuld) — golden rule.
